## ПОСТАНОВКА ЗАДАЧІ

1. [cite_start]Побудувати для задачі лінійного програмування $(Z)$ двоїсту задачу лінійного програмування $(W)$[cite: 23].
2. [cite_start]Розробити програму, за допомогою якої можна розв'язати пару взаємно двоїстих задач $(Z, W)$ симплекс-методом[cite: 24].
3. [cite_start]Розв'язати побудовану двоїсту задачу $(W)$ безпосередньо шляхом підставлення її симплекс-таблиці в практичну роботу № 1.В[cite: 25].
4. [cite_start]Порівняти результати (оптимальні розв'язки), які було отримано під час розв'язання задачі $W$ безпосередньо і шляхом розв'язання пари двоїстих задач[cite: 26].
5. [cite_start]Побудувати для задачі лінійного програмування двоїсту задачу й розв'язати пару взаємно двоїстих задач графічно[cite: 27].

## ВИКОНАННЯ РОБОТИ
[cite_start]Для виконання практичної роботи було розроблено консольний застосунок мовою C#[cite: 56]. [cite_start]Програма забезпечує повний цикл обчислень відповідно до алгоритмів, наведених у методичних вказівках, включаючи роботу з двоїстими задачами[cite: 42, 48].

[cite_start]Для розв’язання пари взаємно двоїстих задач застосовано спільну симплекс-таблицю з подвійними мітками[cite: 34]. [cite_start]Зліва розташовані базисні змінні прямої задачі ($y$) та двоїстої ($u$), зверху — вільні змінні прямої ($x$) та двоїстої ($v$)[cite: 35]. [cite_start]Після кожного кроку модифікованих жорданових виключень (МЖВ) мітки обмінюються місцями одночасно для обох задач[cite: 36]. [cite_start]Розв’язок прямої задачі ($X$) зчитується з останнього стовпця, а розв’язок двоїстої задачі ($U$) — з останнього рядка[cite: 37].

Також використано алгоритм побудови двоїстої задачі за правилами переходу: якщо пряма задача на максимум, то двоїста — на мінімум; обмеженням-нерівностям типу $\le$ відповідають невід’ємні змінні двоїстої задачі; [cite_start]невід’ємним змінним прямої задачі відповідають обмеження-нерівності типу $\ge$ двоїстої задачі[cite: 38, 39].

### Структура програми (Архітектура проєкту)
Архітектуру програмного рішення проілюстровано на діаграмі класів. [cite_start]До основних компонентів системи відносяться[cite: 40]:
* [cite_start]`Matrix` — клас для роботи з матрицями, реалізації кроків МЖВ (`JordanExclude`) та керування подвійними мітками стовпців і рядків (`ColMarkersDual`, `RowMarkersDual`)[cite: 40].
* [cite_start]`InequalitySystem` та `Inequality` — класи для представлення й трансформації системи обмежень та окремих нерівностей[cite: 40].
* [cite_start]`GoalFunction` — клас, що відповідає за цільову функцію та її тип (`GoalFunctionType`)[cite: 40].
* [cite_start]`ComputationResult` — клас для акумуляції кроків обчислень та генерації фінального протоколу[cite: 40].
* [cite_start]`InputHandler` та `ReportPrinter` — статичні класи для забезпечення введення даних користувачем та виведення результатів у консоль[cite: 40].

### Вхідні та вихідні дані
* [cite_start]**Вхідні дані:** кількість змінних ($n=2$), кількість обмежень ($m=2$), коефіцієнти цільової функції та коефіцієнти системи обмежень разом із вільними членами[cite: 46].
* [cite_start]**Вихідні дані:** постановка двоїстой задачі $W$, вхідна спільна симплекс-таблиця, протокол покрокових перетворень МЖВ (пошук опорного та оптимального розв'язків), фінальні вектори розв'язків $X$ та $U$, а також екстремуми функцій $Z(\max)$ та $W(\min)$[cite: 42, 46].

## ВИСНОВКИ
Під час практичної роботи було створено консольний застосунок на C#, який використовує симплекс-метод та модифіковані Жорданові виключення для знаходження оптимального розв'язку двоїстої задачі лінійного програмування[cite: 56]. 

Програма була успішно протестована на індивідуальному варіанті завдання[cite: 57]. Для верифікації результатів задачу також було розв'язано графічно — обидва підходи дали однаковий фінальний результат, що підтверджує правильність розробленого програмного забезпечення та коректність математичних розрахунків[cite: 57].
